# Personal Website

Static personal-site clone based closely on the provided Ronish reference source.
The visual system uses the source OpenRunde fonts, compact text layout, section
rows, hover bands, animated name, and five-stop appearance slider.

The content is filled from the attached Vaibhaav Tiwari resume PDF: contact
links, education, experience, projects, achievements, and skill cards.

## Preview

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000/`.
